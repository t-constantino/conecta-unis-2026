# Conecta Unis 2026

Plataforma conceitual e de demonstração voltada à conexão entre empresas e alunos do Grupo Unis, focada em vagas de estágio, trainees e microdesafios práticos para simplificar processos seletivos.

Desenvolvido como **projeto de extensão do curso de ADS** para fins de **apresentação e avaliação acadêmica**.

> **Status do projeto:** Este projeto é **apenas uma demonstração (demo)**. O site **ainda não funciona de verdade de forma completa ou eficaz** e **não foi aprovado para ser oficializado**. Parte das funcionalidades existe apenas para fins de teste, simulação e apresentação.

## Funcionalidades Disponíveis na Demo

- [x] **Painel Administrativo da Empresa:** Visualização das vagas cadastradas no ambiente de teste.
- [x] **Publicação Dinâmica de Vagas:** Formulário estruturado em etapas com validações de faixa salarial, formato de entrevista e requisitos.
- [x] **Microdesafios Práticos:** Inclusão de testes objetivos com limite de tempo padrão.
- [x] **Compromisso de Feedback:** Configuração de retorno automático para candidatos em até 7 dias.
- [x] **Pré-visualização Interativa:** Visualização da vaga antes do envio final.

## Tecnologias Utilizadas

- **Origem e Build:** Projeto exportado/iniciado a partir do Figma e empacotado com **Vite**
- **Front-end:** **React**, **TypeScript** e **Tailwind CSS**
- **Back-end & Serverless:** Funções serverless na Vercel (`/api`) com **bcryptjs**
- **Banco de Dados:** **Neon PostgreSQL** (`@neondatabase/serverless` / `@vercel/postgres`)
- **Hospedagem & Deploy:** **Vercel** (via GitHub)

## Contexto Acadêmico e Uso

Projeto de extensão universitária desenvolvido para apresentação, avaliação e demonstração tecnológica, sem aprovação oficial para operação real.
